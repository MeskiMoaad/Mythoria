# ⚔️ Mythoria — Jeu de cartes fantastiques

## Présentation du projet

**Mythoria** est un projet pédagogique de développement web réalisé dans le cadre de la formation à YouCode. Il consiste à créer un site web autour d'un jeu de cartes fantastiques, permettant aux joueurs de découvrir des boosters, d'obtenir des cartes, de gérer leur collection et de construire leur propre deck.

## Fonctionnalités

- **Accueil :** présentation de l'univers Mythoria et des cartes.
- **Boutique :** consultation des boosters et gestion du panier.
- **Opening Chamber :** ouverture des boosters et découverte des cartes.
- **My Grimoire :** consultation et organisation de la collection.
- **My Deck :** création et gestion d'un deck personnalisé.

## Technologies utilisées

- HTML5
- Tailwind CSS
- JavaScript
- LocalStorage
- Git et GitHub

## Installation

1. Cloner le dépôt GitHub.
2. Ouvrir le fichier `index.html` dans un navigateur.

## Objectif pédagogique

Ce projet permet de mettre en pratique les bases du développement web, notamment la structuration HTML, la mise en page avec Tailwind CSS et la programmation JavaScript pour rendre le site interactif.
