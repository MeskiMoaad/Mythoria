# ⚔️ Mythoria — Jeu de cartes fantastiques

## Présentation du projet

**Mythoria** est un projet pédagogique de développement web réalisé dans le cadre de la formation à YouCode. Il consiste à créer un site web autour d'un jeu de cartes fantastiques, permettant aux joueurs de découvrir des boosters, d'obtenir des cartes, de gérer leur collection, de construire leur propre deck et de participer à des combats dans une arène.

## Fonctionnalités

- **Accueil :** présentation de l'univers Mythoria et des cartes.
- **Boutique :** consultation des boosters et gestion du panier.
- **Opening Chamber :** ouverture des boosters et découverte des cartes.
- **My Grimoire :** consultation et organisation de la collection.
- **My Deck :** création et gestion d'un deck personnalisé.
- **Arena :** affrontement stratégique contre une intelligence artificielle simple, avec un système de tours, une attribution aléatoire des factions (Lumière et Ténèbres), une gestion des cartes sur le champ de bataille et un système de points de vie (HP).

## Technologies utilisées

- HTML5
- Tailwind CSS
- JavaScript (ES Modules)
- LocalStorage
- Git et GitHub

## Installation

1. Cloner le dépôt GitHub.
2. Ouvrir le projet dans un éditeur de code.
3. Lancer le fichier `index.html` dans un navigateur.
